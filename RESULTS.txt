TRAFFIC-SIGN DETECTION - RESULTS (India, Japan, Singapore, USA)
===============================================================
All models: YOLO11s, Ultralytics 8.4.174, trained on SLURM (NVIDIA A40 / H200).
Test sets are REAL frames never used for training. P = precision, R = recall.
mAP50 = mean AP at IoU 0.5, mAP50-95 = mean AP over IoU 0.5..0.95.

Findings
- The data pipeline matters more than the architecture: v3 beats the old model on the test bed
  0.658 vs 0.361 mAP50 at the same input size.
- The P2 (small-object) head does not help: YOLO11s -3.0 mAP50, YOLO26-L -0.3.
- YOLO11s gives the best accuracy / speed balance (about 120 FPS end-to-end on an A40).


3. VERSION HISTORY
------------------
India      v1 real data, cleaned -> v2 + test-bed video mining (new classes: width limit,
           height limit, charging station) -> v3 short fine-tune for "No parking"
Japan      v2 final; a later fine-tune (v2_ft) was worse on the same val (mAP50-95 0.792 vs 0.830)
Singapore  synthetic-only v1 (many false positives on real video) -> v2 real + synthetic tiles
USA        v2 (0.918 / 0.844) -> v3 + "Other sign" class (0.940 / 0.855, final)
           -> v4 + reviewed video tracks: worse on held-out data, so v3 stays final
